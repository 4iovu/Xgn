# Xgn - 头像/姓名合并显示（SillyTavern 第三方扩展）

## 功能

- 在 SillyTavern「扩展」设置面板中提供独立的 **Xgn** 设置抽屉。
- 支持绑定**多个美化**（即用户设置里的 UI 主题 / Theme）。
- 插件会读取 `#themes` 下拉框中的美化列表，供你在设置里勾选需要绑定的美化。
- 每个绑定的美化，拥有**互相独立**的两个开关：
  - **头像放在一起**：在消息原本的头像位置，额外叠加显示 User 头像 + Char 头像的组合。
  - **姓名放在一起**：在消息原本的姓名位置，额外叠加显示 User 姓名 + Char 姓名的组合。
- 两个开关完全独立，可任意搭配（都开 / 都关 / 只开一个）。
- 未绑定的美化，或已绑定但两个开关都关闭的美化，**完全保持酒馆原本效果**，插件不介入。
- 插件不会把头像、姓名、正文合并成新的整体气泡，只在 ST 原生 DOM 结构基础上**追加**自己的新元素（全部使用 `xgn-` 前缀的新类名），不会更改或复用 ST 原生类名。
- 自动监听新消息渲染、切换聊天、加载历史消息、切换美化等动态变化，保证效果实时生效且不会重复生成元素。
- 响应式设计，桌面端和移动端均可正常显示。

## 安装方法

1. 打开 SillyTavern，进入右上角「扩展」(Extensions) 面板。
2. 点击「安装扩展」(Install Extension)，粘贴本扩展的 Git 仓库地址进行安装；
   或手动将本文件夹整体复制到 `SillyTavern/public/scripts/extensions/third-party/Xgn` 目录下，然后重启/刷新 SillyTavern。

## 使用方法

1. 打开「扩展」设置面板，找到「Xgn - 头像/姓名合并显示」抽屉并展开。
2. 面板中会自动列出你当前所有已导入的美化（即用户设置 - UI 主题里显示的美化名称）。
3. 对想要生效的美化，勾选左侧「绑定」；绑定后即可分别勾选「头像放在一起」「姓名放在一起」。
4. 切换到已绑定并至少开启一项的美化后，聊天消息会自动叠加对应的头像/姓名组合；切换到未绑定的美化则自动恢复原样。
5. 如果你导入了新的美化但列表未刷新，点击「刷新美化列表」按钮即可。

## 文件说明

- `manifest.json`：扩展清单文件。
- `index.js`：核心逻辑（设置面板渲染、消息元素追加/清理、事件监听）。
- `style.css`：新增元素的样式与响应式适配。

## 已知限制

- 群组聊天（多角色群聊）中，"Char" 一侧信息会尽量取当前主角色信息，个别场景下可能与消息实际发送者不完全一致，属于合理的性能与复杂度取舍。
- 若某个自定义美化的 HTML 结构对 `.mesAvatarWrapper` / `.ch_name` 做了大幅度替换（而非纯 CSS 换皮），插件的追加点可能需要相应调整。
